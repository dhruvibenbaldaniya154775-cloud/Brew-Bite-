# Brew & Bite Cafe Website

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser localStorage
- No backend/database/server required

## How to run
1. Extract the ZIP.
2. Open the `Brew-and-Bite` folder.
3. Double-click `index.html`.
4. Register a customer account and test ordering/reservation flows.
5. Admin demo login:
   - Email: `admin@brewandbite.com`
   - Password: `admin123`

## Customer flow
Register -> Login -> Menu -> Product -> Cart -> Checkout -> My Orders

## Reservation flow
Login -> Reservation -> Submit -> My Reservations

## Admin flow
Admin Login -> Dashboard -> Products -> Orders -> Customers -> Reservations

## Data
All demo data is stored in browser localStorage. Clearing browser site data will clear the demo records.
